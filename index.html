Backend Setup (Super Admin)

Cloud Functions and Security Rules must run on Firebase's servers, not in the browser. This page holds their complete code so this one HTML file contains everything. Copy each block to the place shown.

  1. Firebase Console > Authentication > Sign-in method: enable Email/Password and Google; add your website domain under Settings > Authorized domains.
  2. Spark plan: do NOT upgrade. Cloud Functions need Blaze, so the functions files below are an optional, future reference and are not used. Accounts are created through invitations and every permission is enforced by the Firestore rules.
  3. Skip the functions deployment on Spark. Do not run firebase deploy --only functions.
  4. Paste the two rules into the Console and Publish (or run firebase deploy --only firestore:rules,storage, which works on Spark). Publish the new Firestore rules before anyone uses the invitation login.
  5. Existing users must verify their email once. If an old account's email cannot receive mail, add the boolean field verificationBypass = true to its users/<uid> document in Firestore.

functions/index.js (optional - needs Blaze, not used on Spark)

Create a folder named functions in your Firebase project and save this as functions/index.js.
